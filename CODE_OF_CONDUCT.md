# Código de Conduta

Este projeto existe para ajudar pessoas que estão tentando parar de usar drogas. Muita gente que contribui, testa ou
abre issues vive isso de perto. Por isso, aqui a regra é cuidado.

## O que esperamos

- Respeito e acolhimento, inclusive com quem relata uma recaída.
- Nenhum julgamento moral sobre uso de drogas, tratamento ou crenças (religiosas, espirituais ou nenhuma).
- Críticas ao trabalho, nunca às pessoas.
- Privacidade: não peça nem divulgue informações pessoais ou de saúde de ninguém.

## O que não aceitamos

- Assédio, insultos, humilhação, discriminação de qualquer tipo.
- Estigmatizar quem usa drogas ("viciado", "fraco", "sem vergonha").
- Expor dados de terceiros, inclusive prints com informações reais.
- Incentivar uso de drogas ou divulgar formas de obtê-las.

## Se algo acontecer

Fale com quem mantém o projeto por uma mensagem privada ou pela aba de segurança do repositório
("Report a vulnerability"), descrevendo o ocorrido. Toda denúncia é tratada com sigilo. Quem descumprir este código
pode ter comentários removidos ou ser bloqueado do projeto.

Inspirado no [Contributor Covenant 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).
